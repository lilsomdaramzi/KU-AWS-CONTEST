# 데이터 명세

대상 파일: `DATA/장학공지_crawling.csv`

| 열 | 설명 | 형식·허용값 | 공란 의미 |
|---|---|---|---|
| 제목 | 정규화된 장학 프로그램 또는 학자금 대출 이름 | `~장학금`, `~장학생 선발`, `~학자금 대출` 중심의 문자열 | 사용하지 않음 |
| 성격 | 제목과 기관명을 바탕으로 분류한 유형 | `외부장학`, `교내/일반장학`, `국가장학`, `공지/안내` | 분류할 수 없음 |
| 신청날짜 | 신청 시작월 기준 분기 | `1분기`, `2분기`, `3분기`, `4분기` | 웹 본문에서 신청기간을 확인할 수 없음 |
| 지원대상 | 핵심 자격을 요약한 쉼표 구분 문구 | 학적·거주지·소득·특수자격, 최대 4개 조건 | 웹 본문에 대상이 없거나 신뢰할 수 있게 추출되지 않음 |
| 금액 | 개인 기준 지원금 | `숫자만원`, `최대 숫자만원`, `전액` | 웹 본문에서 개인 지급액을 확인할 수 없음 |

## 신청날짜 분기 기준

| 월 | 분기 |
|---|---|
| 1~3월 | 1분기 |
| 4~6월 | 2분기 |
| 7~9월 | 3분기 |
| 10~12월 | 4분기 |

기간이 두 분기에 걸쳐 있으면 신청 시작월의 분기를 사용합니다.

## 금액 예시

| 원문 표현 | 저장값 |
|---|---|
| 1인당 150만원 | 150만원 |
| 대학생 최대 100만 원 | 최대 100만원 |
| 한도 50만원 | 최대 50만원 |
| 4,200,000원 | 420만원 |
| 최대 8백만원 | 최대 800만원 |
| 등록금 전액 지원 | 전액 |

금액 앞의 대상 표현과 `1인당`은 제거하며, 허용 접두어는 `최대`뿐입니다.

## 지원대상 예시

- `고등학생·대학 신입생, 논산시 1년 이상 거주자·자녀`
- `재학생, 학자금 지원구간 0~4구간`
- `대학 재학생, 휴학생 제외, 5자녀 이상 가구`
- `고속도로 사고 피해자·자녀, 중증장애인·자녀`

## 인코딩

CSV는 Excel에서 한글이 정상 표시되도록 UTF-8 BOM(`utf-8-sig`)으로 저장합니다.
