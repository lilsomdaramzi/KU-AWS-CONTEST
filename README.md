# 고려대학교 세종캠퍼스 장학공지 데이터

고려대학교 세종캠퍼스 장학공지 게시판의 1~20페이지와 각 상세 글을 수집하고, 실제 장학 프로그램 탐색에 필요한 필드만 정규화한 데이터셋입니다.

## 저장소 구조

```text
KU-AWS-CONTEST/
├─ DATA/
│  └─ 장학공지_crawling.csv
├─ SCRIPT/
│  ├─ crawl_scholarship.py
│  └─ postprocess_scholarship.py
├─ 설명/
│  ├─ 데이터_생성과정.md
│  └─ 데이터_명세.md
├─ README.md
├─ requirements.txt
└─ .gitignore
```

## 데이터 요약

- 파일: `DATA/장학공지_crawling.csv`
- 레코드: 170건(헤더 제외)
- 열: `제목`, `성격`, `신청날짜`, `지원대상`, `금액`
- 인코딩: UTF-8 with BOM(`utf-8-sig`), Excel 호환
- 범위: 장학공지 게시판 1~20페이지

## 출처

- [교내장학금 신청 및 선발 안내](https://gpa.korea.ac.kr/koreaSejong/7953/subview.do)
- [고려대학교 세종캠퍼스 장학공지](https://secu.korea.ac.kr/koreaSejong/7906/subview.do)

## 설치

Python 3.12 환경에서 확인했습니다.

```powershell
python -m pip install -r requirements.txt
```

## 실행

저장소 루트에서 실행합니다.

```powershell
python SCRIPT/crawl_scholarship.py
```

실행하면 장학공지 1~20페이지와 상세 페이지를 다시 수집해 `DATA/장학공지_crawling.csv`를 갱신합니다. 사이트 응답 상황에 따라 수 분 이상 걸릴 수 있습니다.

기존 CSV에 정규화·제외 규칙만 다시 적용하려면 다음을 실행합니다.

```powershell
python SCRIPT/postprocess_scholarship.py
```

## 주요 정제 규칙

- 제목을 `~장학금`, `~장학생 선발`, `~학자금 대출` 중심으로 표준화
- 신청 시작월을 기준으로 `1분기`~`4분기` 분류
- 지원대상을 학적·거주지·소득·특수자격 중심의 짧은 문구로 요약
- 금액을 `숫자만원`, `최대 숫자만원`, `전액` 형식으로 통일
- 계좌 등록, 문의 모음, 일반 행정 일정 등 비프로그램 공지 제외
- 근로장학 및 명시적 시급 지급형 프로그램 제외
- 총사업 예산을 개인 지원금으로 잘못 인식하지 않도록 필터링

자세한 과정과 필드 정의는 [`설명/데이터_생성과정.md`](설명/데이터_생성과정.md), [`설명/데이터_명세.md`](설명/데이터_명세.md)를 참고하세요.
